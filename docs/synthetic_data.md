# 합성 데이터

생성기: `src/commerce_lab/datagen/`. 실행:

```
python -m commerce_lab.datagen.generator --out data/generated            # 새 랜덤 시드 (출력에 시드가 찍힌다)
python -m commerce_lab.datagen.generator --seed 42 --out data/generated   # 같은 시드는 같은 데이터
```

시드를 주지 않으면 매번 새 랜덤 시드를 쓴다(리프레시 Job은 매일 새 시드). 같은 시드는 항상 동일한 데이터를 만든다(`generate_all`의 기본값은 `42`, 테스트용). 날짜 범위는 2026-05-25 ~ 2026-09-21(120일)로 고정이라, 시드가 바꾸는 것은 날짜가 아니라 주문·마케팅·재고 값이다.

**시나리오 보장.** 랜덤 시드에서는 심은 효과가 표본 잡음에 가려지거나, 잡음이 엉뚱한 세그먼트를 high로 밀어 올릴 수 있다. 그래서 `generate_all`은 한 번 생성한 뒤 `plant_check.planted_scenario_failures`로 4개 시나리오가 high 임계값을 여유 있게 넘는지, 심지 않은 세그먼트는 high 임계값을 넘지 않는지 확인하고, 아니면 같은 시드에서 파생한 다음 시도로 다시 생성한다(최대 50회). 그래서 어떤 시드든 high 이슈는 정확히 심은 4개이고, 시드는 여전히 데이터를 재현한다. 잡음으로 생기는 medium/low 이슈는 의도적으로 허용한다. 실측 통과율은 시도 1회당 약 60%다.

**아카이브.** 매일 새 데이터가 `raw/commerce/날짜/`에 쌓이고 같은 폴더의 `seed.txt`에 시드가 기록된다. 하루 약 0.4MB라 앱(스냅샷 JSON 1개만 읽음)에는 영향이 없다.

## 데이터셋

| 파일 | 그레인 | 비고 |
|---|---|---|
| `orders.csv` | 주문 1건당 1행 | 브랜드, 채널, SKU, 고객, 수량, 가격, 할인, 순매출, `is_new_customer` 플래그 |
| `marketing.csv` | 브랜드 x 마케팅 채널 x 일 | 지출, 노출수, 클릭수, 기여 주문/매출 |
| `inventory.csv` | SKU x 일 | 기초/기말 재고, 입고, 판매 수량 |
| `customers.csv` | 고객 1명당 1행 | `orders.csv`에서 파생: 획득 채널, 최초 주문일, 누적 주문수/금액, `is_returning` |
| `skus.csv` | SKU 1개당 1행 | 브랜드, 기준가, 단위 원가 |

엔티티: 브랜드 3개(Aurora, Kestrel, Marlow) x 판매 채널 3개 x 마케팅 채널 3개 x 브랜드당 SKU 8개(총 24개) x 고객 풀 900명. 볼륨은 의도적으로 작다(주문 ~1,600건, 재고 행 ~2,900개).

기간의 마지막 30일("최근")을 그 이전 30일("베이스라인")과 비교해 아래 시나리오들을 탐지한다.

## 심어놓은 시나리오

4개 시나리오 모두 `tests/test_datagen/test_scenarios.py`에서 (생성기 내부 로직이 아니라 CSV 출력값을 집계해서) 독립적으로 검증한다.

1. **마케팅 효율 악화** — Kestrel / `paid_social`: 최근 구간에서 지출이 ~2.6배로 늘지만 기여 매출은 그대로라 ROAS가 붕괴한다. 다른 브랜드/채널 조합은 지출-매출 관계가 안정적으로 유지된다.
2. **수요 증가 + 재고 부족** — SKU `AUR-003`(Aurora): 최근 구간에서 수요 비중이 ~2.8배로 커지는 동시에 입고는 거의 0으로 줄어, 기말 재고와 재고 소진 일수가 기간 말에 급격히 떨어진다. 다른 모든 SKU는 반응형 재입고 정책(입고량이 지난 1주 실제 수요를 따라감)을 써서 기간 전체에 걸쳐 ~20~35일의 안정적인 소진 일수를 유지하므로 M4 재고 규칙에 걸리지 않는다.
3. **한 세그먼트에 집중된 매출 하락** — Marlow / `retail_partner`: 최근 구간에서 해당 세그먼트의 주문 비중이 줄어, 전체 매출은 대체로 평탄한 반면 그 브랜드/채널 조합에서만 실질적인 순매출 하락이 발생한다.
4. **신규 vs 재구매 비중 변화** — 신규 고객이 주문을 낼 확률이 베이스라인 ~55%에서 최근 ~20%로 떨어져, 주문 구성이 재구매 고객 쪽으로 이동한다.

정확한 파라미터는 `src/commerce_lab/datagen/config.py`의 `SCENARIO_*` 상수에 단일 출처로 존재한다.

## 검증

```
python -m pytest tests/test_datagen -q
```
